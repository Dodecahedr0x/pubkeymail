# Render Deployment

PubKeyMail deploys to Render with the root `render.yaml` Blueprint.

## Resources

The Blueprint creates:

- `pubkeymail-api`: Node web service for the Express API.
- `pubkeymail-web`: Node web service for the Next.js app.
- `pubkeymail-postgres`: PostgreSQL database.
- `pubkeymail-redis`: Redis-compatible key-value store.

The API build runs `npm ci && npm run build:api`. The API start command runs migrations before starting the server:

```bash
npm run migrate && npm run start
```

The web build runs `npm ci && npm run build:web`. The web start command binds Next.js to Render's public interface:

```bash
npm --prefix web run start -- --hostname 0.0.0.0
```

## Apply The Blueprint

The Blueprint deploys `https://github.com/Dodecahedr0x/pubkeymail` from the
repository's `master` branch. Keep both service definitions synchronized if the
repository URL or default branch changes.

1. Commit and push `render.yaml` to `master`.
2. Open the Render Blueprint flow:
   `https://dashboard.render.com/blueprint/new?repo=https://github.com/Dodecahedr0x/pubkeymail`
3. Fill the secret and deployment-specific environment variables listed below.
4. Apply the Blueprint.
5. After deployment, verify:
   - API liveness: `https://<api-host>/health/live`
   - API readiness: `https://<api-host>/health/ready`
   - Web app: `https://<web-host>/`

## Required Dashboard Values

Set these on `pubkeymail-api`:

```env
DOMAIN=https://<api-host>
CORS_ORIGIN=https://<web-host>
ALLOWED_HOSTS=<api-host>,<custom-api-host>
SMTP_API_KEY=<provider-api-key>
SMTP_WEBHOOK_SECRET=<provider-webhook-secret>
SMTP_FROM_DOMAIN=<mail-domain>
JWT_SECRET=<at-least-32-characters>
SOLANA_PAY_MERCHANT_WALLET=<merchant-wallet>
ETHEREUM_RPC_ENDPOINT=<optional-ethereum-rpc-url>
SENTRY_DSN=<optional-sentry-dsn>
```

Set this on `pubkeymail-web` before building the web service:

```env
NEXT_PUBLIC_API_URL=https://<api-host>/api/v1
```

`DATABASE_URL` and `REDIS_URL` are generated by Render from the Blueprint database references. Do not set them manually unless replacing the managed Render resources.

## Notes

- The API explicitly binds to `0.0.0.0:$PORT` for Render.
- `SOLANA_PAY_USDC_MINT` must match `SOLANA_CLUSTER`; the Blueprint defaults to mainnet-beta/mainnet USDC and expires payment requests after 900 seconds.
- Both Git-backed services declare `repo` explicitly, as required by Render's Blueprint validator.
- `NEXT_PUBLIC_API_URL` is compiled into the Next.js bundle, so changing it requires a web redeploy.
- The Railway/Nixpacks deployment files were removed; Render is the deployment target for this repo.
